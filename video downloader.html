Low-Level Architecture

JavaScriptBridge
Injected JS evaluated at page load. Hooks XMLHttpRequest.open, fetch(), MediaSource.addSourceBuffer, HTMLVideoElement.src. Posts signals to Android via @JavascriptInterface.
WebViewClientInterceptor
Overrides shouldInterceptRequest(). Inspects every outgoing HTTP request URL and response headers. Clones Content-Type, Content-Length, Cookie, Referer for reuse in download phase.
NetworkSignalBus
Kotlin SharedFlow hot stream. Receives raw signals from bridge and interceptor. Emits deduplicated MediaSignal events to all downstream subscribers.
MediaClassifier
Regex + MIME-type decision tree. Classifies URLs as MP4/WebM/HLS/DASH/Blob/Unknown. Assigns confidence score 0–1. Filters noise (ads, trackers, tiny files).
ManifestResolver
Fetches and parses M3U8/MPD manifests. Enumerates quality streams. Resolves relative segment URLs to absolute. Extracts EXT-X-KEY for DRM detection.
SegmentDownloadWorker
Coroutine-based CoroutineWorker. Manages parallel segment downloads with bounded Semaphore(8). Writes chunks to temp dir. Reports byte progress via setProgressAsync().
MuxPipeline
Invokes FFmpeg-kit to concatenate TS segments or mux separate audio+video DASH streams into final MP4. Cleans temp files on completion or failure.
BlobExtractor
JS injection intercepts SourceBuffer.appendBuffer, serialises binary ArrayBuffer to Base64 via btoa, transfers chunks through @JavascriptInterface. Reconstructed on Android side.

Header Re-use Strategy

When shouldInterceptRequest() fires, the system clones the WebResourceRequest headers including Cookie, Referer, Origin, User-Agent, and Authorization. These are stored in a HeaderStore (URL-keyed LRU cache, TTL 30 min, backed by Android Keystore). On download initiation, headers are retrieved from HeaderStore and injected into every OkHttp request made by the download engine — enabling authenticated downloads of gated CDN content. Cookies are refreshed via a background probe if TTL is exceeded.

Interception Points (all run in parallel)
shouldInterceptRequest
Every HTTP/S request the WebView makes. Highest fidelity for URL + headers.
XHR.open hook
Captures AJAX-based segment requests including encrypted .ts URLs.
fetch() proxy
ES6 fetch interception covers SPA-style streaming video requests.
video.src setter
Captures direct MP4 assignments, object URLs, and blob: URIs.
MSE addSourceBuffer

Media Detection Pipeline

Stage 1 — Signal Ingestion
Source AshouldInterceptRequest(WebResourceRequest) — captures full URL + all request headers from every network call
Source BInjected JS @JavascriptInterface callback — captures XHR/fetch/video.src/blob before the network layer
Source ConLoadResource() — secondary fallback for resource URLs missed by interceptor
MergeAll sources publish to networkSignalBus: MutableSharedFlow<MediaSignal>
Stage 2 — URL Classification (MediaClassifier)
Pattern matching rules (priority order)
1. File extension: .m3u8 .mpd .mp4 .webm .mkv .flv .ts
2. Path segment: /hls/ /dash/ /stream/ /video/ /media/
3. Query params: ?format=hls, ?type=video
4. MIME header: video/* audio/* application/x-mpegURL
5. Content-Length heuristic: >500KB = likely video
Classification output types
DIRECT_MP4, DIRECT_WEBM, HLS_MASTER, HLS_MEDIA, DASH_MPD, BLOB_MSE, PROGRESSIVE_STREAM, UNKNOWN

Confidence: 0.0–1.0. Threshold >0.6 required to surface in UI.
Stage 3 — Metadata Enrichment
TitleExtracted from document.title via JS, or URL path parsing as fallback
ThumbnailWebView screenshot capture or og:image meta tag extraction via JS
DurationRead from video.duration JS property, or EXT-X-TARGETDURATION sum from M3U8
Quality listFrom master M3U8 BANDWIDTH+RESOLUTION attributes or MPD AdaptationSet Representations
File sizeContent-Length header for direct files; estimated from bitrate×duration for adaptive streams
Stage 4 — Deduplication & Filtering
Deduplication
SHA-256 hash of URL after stripping dynamic tokens (t=, token=, exp=, sign=). Per-tab HashSet, cleared on tab close.
Noise filters
Reject: ad networks (domain blocklist), files <100KB, audio-only streams, tracking pixels, thumbnail images (image/* MIME).

Parallel Segment Download Architecture

A SegmentDownloadWorker receives a List<SegmentUrl>. It launches a coroutine per segment, bounded by Semaphore(maxConcurrent = 8). Each coroutine calls OkHttpClient.newCall(request).execute() and streams the response body to a numbered temp file at cacheDir/downloads/{downloadId}/seg_{n}.ts. A ConcurrentHashMap<Int, Boolean> tracks per-segment completion. Progress is emitted as (completedSegments / totalSegments) * 100 to a MutableStateFlow observed by the notification manager and UI layer.

URL Resolution Strategy

Segment URLs may be absolute (https://cdn.example.com/seg1.ts), path-relative (/hls/seg1.ts), or base-relative (seg1.ts). The parser resolves all via java.net.URI.resolve(base, relative). Base URL is the URL of the media playlist. Query parameters from the base URL are preserved and appended to segment URLs when the site uses token-based CDN auth (common pattern: ?token=xxx&expires=yyy must be forwarded on every segment request).

Live vs VOD Handling
VOD (EXT-X-ENDLIST present)
Segment list is fixed. Download all sequentially/parallel. Mux once complete.
Live (no EXT-X-ENDLIST)
Poll playlist every targetDuration. Append new segments to queue. Record for N minutes. User-stop or EXT-X-ENDLIST appearance triggers mux.

Blob URL Architecture

The Blob Problem

Blob URLs (blob:https://example.com/uuid) are ephemeral object URLs referencing in-memory Blob or MediaSource objects. They cannot be fetched from outside the originating JS context. Standard HTTP interception yields nothing — the video data lives only in the browser's JS heap. A completely different capture strategy is required.

Strategy 1 — MSE Buffer Capture (Primary)
1
Detect MediaSource usage
JS hook: override MediaSource.prototype.addSourceBuffer to flag the video element
2
Hook appendBuffer
SourceBuffer.prototype.appendBuffer intercepted → receives raw ArrayBuffer for every segment
3
Serialise to Base64
btoa(String.fromCharCode(...new Uint8Array(buffer))) — chunked in 256KB blocks to avoid JS heap OOM
4
Transfer to Android
JavascriptInterface.onBlobChunk(base64, chunkIndex, isLast) called per chunk
5
Reconstruct + write
Android decodes Base64 chunks → writes raw bytes to temp file → mux with FFmpeg into MP4
Strategy 2 — Fetch Injection (Fallback)

For blob: URLs directly set on video.src (not MSE-backed), inject JS that calls fetch(blobUrl) to obtain the Blob object, converts it to ArrayBuffer via blob.arrayBuffer(), then serialises and transfers identically to Strategy 1. Works for Blob objects created by URL.createObjectURL(blob) from a Fetch or XHR response body.

Limitations & Fallbacks
Size constraint
Base64 transfers of large binary over the JS bridge are slow (~2–3× slower than direct download). Recommend only for files under ~200MB. Larger → alert user to use network capture mode.
Encrypted MSE (EME / Widevine)
If Encrypted Media Extensions are active, buffers are ciphertext. Capture yields encrypted data. Cannot decrypt without CDM key. UI must warn: "DRM-protected content — download not available."

Location: getExternalCacheDir()/soul_downloads/{id}/
Content: in-progress segment files (seg_000.ts), partially merged files. Auto-cleaned on completion or app restart. Not visible to user via file manager.

Thumbnail cache: filesDir/thumbs/{hash}.webp (Coil-managed). Encrypted vault for sensitive content: EncryptedFile with AES-256-GCM (Jetpack Security Crypto).

SAF folder picker via ACTION_OPEN_DOCUMENT_TREE. DocumentFile API for writing. URI persisted via takePersistableUriPermission(READ|WRITE). Survives reboots.

Low disk guardCheck StatFs.getAvailableBlocksLong() before download start. Warn if <500MB free. Block if <100MB.

Security Architecture

Header Security
Cookies stored in memory only during session. Never written to disk in plaintext. HeaderStore uses Android Keystore-backed AES-GCM encryption for persistent caching. TTL enforced; expired entries purged.
JS Bridge Security
@JavascriptInterface methods accept only typed primitives. Input validated and length-limited. Bridge is explicitly removed during page navigation to prevent cross-origin exploitation of the interface.
URL Validation
All URLs piped through Patterns.WEB_URL + custom scheme allowlist (https, http only). Reject javascript:, data:, file:, intent: schemes from media pipeline. SSRF prevention: block RFC-1918 download targets.
Certificate Pinning
OkHttp CertificatePinner on all download engine requests to first-party endpoints. WebView traffic uses system trust store (intentionally not pinned — would break user-specified sites).
File Output Security
FileProvider for all file sharing. Content URI only — no raw file:// URIs exposed. Output files not executable (permissions 644). Temp directory not accessible to other apps via Scoped Storage.
DRM Awareness
Detect Widevine/PlayReady via EME API inspection in JS. Surface "DRM protected" warning in UI. Do NOT attempt decryption. AES-128 HLS (non-DRM) detected by EXT-X-KEY; key URI fetched and passed to FFmpeg for transparent mux; content not re-encrypted at rest.

fun harvestHeaders(request: WebResourceRequest): HarvestedHeaders {
  val h = request.requestHeaders
  return HarvestedHeaders(
    cookie        = h["Cookie"],
    referer       = h["Referer"] ?: request.url.toString(),
    origin        = h["Origin"],
    userAgent     = h["User-Agent"] ?: DEFAULT_UA,
    authorization = h["Authorization"]
  )
}

fun buildDownloadRequest(url: String): Request {
  val urlHash = SHA256.hash(normaliseUrl(url))
  val stored  = headerStore.get(urlHash)
  
  return Request.Builder()
    .url(url)
    .apply {
      stored?.cookie        ?. let { addHeader("Cookie", it) }
      stored?.referer       ?. let { addHeader("Referer", it) }
      stored?.authorization ?. let { addHeader("Authorization", it) }
      addHeader("User-Agent", stored?.userAgent ?: DEFAULT_UA)
    }
    .build()
}
Error Handling in Intercept Path
NullPointerException in headers
WebResourceRequest.requestHeaders may return null on some WebView versions. Wrap in ?.let — if null, emit signal with empty headers map and proceed. Headers are optional for detection; required only for download.
Thread safety
shouldInterceptRequest runs on a background thread (not main). HeaderStore must be thread-safe. Use ConcurrentHashMap internally. Never touch UI state directly from this callback.
Header TTL expiry during download
If headers were captured 31+ minutes ago, TTL is expired. On download start, check capturedAt + ttlMs < now. If expired → emit a header re-probe request by loading the video page URL silently, then retry header harvest.

          const isLast  = (i + CHUNK) >= u8.length;

class JavaScriptBridge @Inject constructor(
  private val signalBus: NetworkSignalBus,
  private val blobEngine: BlobDownloadEngine,
  private val scope: CoroutineScope
) {
  private val tabId = AtomicReference<String>()

  @JavascriptInterface
  fun onUrl(url: String, sourceType: String) {
    if (url.length > 4096) return  // length guard against JS injection attacks
    val source = when(sourceType) {
      "XHR"       -> SignalSource.XHR_HOOK
      "FETCH"     -> SignalSource.FETCH_HOOK
      "VIDEO_SRC" -> SignalSource.VIDEO_SRC
      else        -> SignalSource.XHR_HOOK
    }
    scope.launch(Dispatchers.Default) {
      signalBus.emit(MediaSignal(url, source, tabId.get()))
    }
  }

  @JavascriptInterface
  fun onBlobChunk(b64: String, chunkIndex: Int, isLast: Boolean) {
    if (b64.length > 400000) return  // max 300KB per chunk after base64 overhead
    scope.launch(Dispatchers.IO) {
      blobEngine.onBlobChunk(b64, chunkIndex, isLast)
    }
  }

  @JavascriptInterface
  fun onMseDetected(mimeType: String) {
    // Signal that this page uses MSE — pre-allocate blob capture buffer
    scope.launch { blobEngine.prepareCapture(tabId.get(), mimeType) }
  }

  @JavascriptInterface
  fun onDrmDetected(keySystem: String) {
    // e.g. "com.widevine.alpha", "com.microsoft.playready"
    scope.launch { signalBus.emitDrmSignal(keySystem, tabId.get()) }
  }
}
Edge Cases in JS Bridge
btoa() overflow for large binary buffers
btoa(String.fromCharCode(...bigArray)) throws RangeError if the array exceeds ~65,000 elements (call stack size). Solution: chunk the Uint8Array into 256KB slices before btoa conversion. Each chunk independently base64-encoded and bridged as a separate call with sequential chunkIndex.
Bridge torn down during navigation
When WebView navigates, the JS context is destroyed. Calls to SoulBridge.* after navigation throw. All bridge calls wrapped in try-catch on the JS side. Android side: @JavascriptInterface methods are idempotent and defensive — stale calls are safely ignored.

NetworkSignalBus Internal State
@Singleton
class NetworkSignalBus @Inject constructor() {

  // Hot shared flow — 0 replay, 64-slot buffer, DROP_OLDEST on overflow
  private val _signals = MutableSharedFlow<MediaSignal>(
    extraBufferCapacity = 64,
    onBufferOverflow    = BufferOverflow.DROP_OLDEST
  )
  val signals: SharedFlow<MediaSignal> = _signals.asSharedFlow()

  // Per-tab seen URL hashes — deduplication within a page session
  private val seenHashes = ConcurrentHashMap<String, ConcurrentHashSet<String>>()

  suspend fun emit(signal: MediaSignal) {
    val normalised = urlNormalizer.normalise(signal.url)
    val hash       = SHA256.hash(normalised)
    val tabHashes  = seenHashes.getOrPut(signal.tabId) { ConcurrentHashSet() }

    if (tabHashes.add(hash)) {         // returns false if already present
      _signals.emit(signal.copy(normalisedUrl = normalised, urlHash = hash))
    }
    // If already seen: silently drop — no event emitted
  }

  fun resetTab(tabId: String) {
    seenHashes.remove(tabId)           // clear on tab close or page navigate
  }
}

private suspend fun processSignal(signal: MediaSignal) {
  // Step 1: Quick noise filter (synchronous, no I/O)
  if (isDefiniteNoise(signal.url)) return

  // Step 2: Classify URL
  val classification = classifier.classify(signal.url, signal.mimeHint)
  if (classification.confidence < 0.6f) return   // below threshold — drop

  // Step 3: Build skeleton DetectedMedia entity
  val media = DetectedMedia(
    id            = signal.urlHash,
    url           = signal.url,
    normalisedUrl = signal.normalisedUrl,
    type          = classification.mediaType,
    confidence    = classification.confidence,
    tabId         = signal.tabId,
    detectedAt    = signal.timestamp
  )

  // Step 4: Persist skeleton to Room (immediately visible in UI)
  mediaRepository.insertOrIgnore(media)

  // Step 5: Async metadata enrichment (non-blocking)
  scope.launch(Dispatchers.IO) {
    enrichMetadata(media, signal.headers)
  }

  // Step 6: Update UI StateFlow
  refreshDetectedList()
}

Classification Algorithm — Weighted Scoring System
fun classify(url: String, mimeHint: String?): ClassResult {
  var score   = 0.0f
  var guessed = MediaType.UNKNOWN

  // ── Rule Group 1: File extension (weight: 0.85) ──
  val ext = url.substringAfterLast('.').lowercase().substringBefore('?')
  when(ext) {
    "mp4", "m4v"  -> { score += 0.85f; guessed = MediaType.DIRECT_MP4  }
    "webm"        -> { score += 0.85f; guessed = MediaType.DIRECT_WEBM }
    "mkv", "avi"  -> { score += 0.80f; guessed = MediaType.DIRECT_MP4  }
    "m3u8"        -> { score += 0.95f; guessed = MediaType.HLS_MASTER  }
    "ts"          -> { score += 0.75f; guessed = MediaType.HLS_MEDIA   }
    "mpd"         -> { score += 0.95f; guessed = MediaType.DASH_MPD   }
    "m4s", "fmp4" -> { score += 0.80f; guessed = MediaType.DASH_MPD   }
  }

  // ── Rule Group 2: MIME type hint (weight: +0.90) ──
  if (mimeHint != null) {
    when {
      mimeHint.startsWith("video/")                      -> score += 0.90f
      mimeHint == "application/x-mpegURL"                 -> { score += 0.90f; guessed = MediaType.HLS_MASTER }
      mimeHint == "application/vnd.apple.mpegurl"         -> { score += 0.90f; guessed = MediaType.HLS_MASTER }
      mimeHint == "application/dash+xml"                  -> { score += 0.90f; guessed = MediaType.DASH_MPD  }
      mimeHint.contains("mp2t") || mimeHint.contains("mpeg") -> score += 0.70f
      mimeHint == "application/octet-stream"               -> score += 0.25f  // weak hint
    }
  }

  // ── Rule Group 3: URL path patterns (weight: +0.45) ──
  val path = url.lowercase()
  if (path.contains("/hls/") || path.contains("/hlsstream/"))    score += 0.45f
  if (path.contains("/dash/") || path.contains("/dashstream/"))  score += 0.45f
  if (path.contains("/video/") || path.contains("/stream/"))     score += 0.35f
  if (path.contains("/media/") || path.contains("/content/"))    score += 0.20f
  if (path.contains("/playlist") || path.contains("/manifest"))  score += 0.40f

  // ── Rule Group 4: Query parameter patterns ──
  if (url.contains("format=hls"))          { score += 0.50f; guessed = MediaType.HLS_MASTER }
  if (url.contains("type=video"))           score += 0.30f
  if (url.contains("mime=video"))           score += 0.35f

  // ── Rule Group 5: Blob URL detection ──
  if (url.startsWith("blob:")) {
    return ClassResult(MediaType.BLOB_MSE, 1.0f)  // definite
  }

  // ── Normalise score: cap at 1.0 ──
  score = score.coerceAtMost(1.0f)

  // ── Fallback: if score barely above threshold but no type yet ──
  if (guessed == MediaType.UNKNOWN && score >= 0.6f)
    guessed = MediaType.PROGRESSIVE

  return ClassResult(guessed, score)
}

fun normaliseUrl(raw: String): String {
  val uri = Uri.parse(raw)
  val STRIP_PARAMS = setOf("t", "token", "exp", "expires", "sign",
                            "signature", "ts", "nonce", "_", "cb")

  val filteredParams = uri.queryParameterNames
    .filter { it !in STRIP_PARAMS }
    .sorted()  // canonical ordering
    .associate { it to uri.getQueryParameter(it) }

  return Uri.Builder()
    .scheme(uri.scheme)
    .authority(uri.host)
    .path(uri.path.lowercase())
    .apply { filteredParams.forEach { (k, v) -> appendQueryParameter(k, v) } }
    .build().toString()
}

URL Classification Engine

Noise Filter Pipeline
Size filter: Content-Length < 100,000 bytes
If Content-Length header present and value < 100KB → reject. Thumbnail images, small audio clips, tracking beacons all eliminated here.
Ad network domain blocklist
SHA-1 domain hash checked against compiled-in blocklist (~5,000 ad/tracker domains). Match → immediate reject. Blocklist loaded from assets on first classify() call, stored in HashSet<String>.
Audio-only MIME rejection
If mimeHint matches audio/mpeg, audio/ogg, audio/aac without video/* also present → score penalised to below threshold. Audio-only streams not downloadable unless explicitly enabled.
Confidence threshold gate: score < 0.6
Even if URL passes all previous filters, classification confidence below 0.60 → signal dropped silently. Not stored, not shown to user. 0.6–0.8 = "probable video" shown with lower priority. 0.8+ = definite video.
Deduplication hash check
Normalised URL → SHA-256 → check per-tab HashSet. Already present → drop. New → add to set and continue to enrichment.

      val frameRate  = attrs["FRAME-RATE"]?.toFloatOrNull()

      val (width, height) = resolution?.split("x")
        ?. let { Pair(it[0].toIntOrNull() ?: 0, it[1].toIntOrNull() ?: 0) }
        ?: Pair(0, 0)

      val playlistUrl = if (i + 1 < lines.size) {
        URI.resolve(baseUrl, lines[i + 1].trim()).toString()
      } else null

      if (playlistUrl != null) {
        options.add(QualityOption(
          label      = if (height > 0) "${height}p" else "${bandwidth/1000}kbps",
          bandwidth  = bandwidth,
          width      = width,
          height     = height,
          codecs     = codecs,
          frameRate  = frameRate,
          playlistUrl = playlistUrl
        ))
      }
    }
    i++
  }
  return options.sortedByDescending { it.height }
}

Segment-Level Retry Pseudocode
private suspend fun downloadSegmentWithRetry(
  seg: Segment,
  request: Request,
  destFile: File
): Boolean {
  val MAX_ATTEMPTS  = 3
  val BASE_DELAY_MS = 1000L

  repeat(MAX_ATTEMPTS) { attempt ->
    try {
      val response = okHttpClient.newCall(request).await()

      return when(response.code) {
        200, 206 -> {
          response.body!!.byteStream().use { src ->
            destFile.outputStream().use { dst -> src.copyTo(dst) }
          }
          true
        }
        401, 403 -> {
          // Auth failure — refresh cookies and retry once
          if (attempt == 0) { refreshAuth(seg.url); return@repeat }
          false  // second auth failure = give up
        }
        404       -> false    // segment gone — don't retry
        429       -> {
          // Rate limited — extract Retry-After or use longer backoff
          val retryAfter = response.header("Retry-After")?.toLongOrNull() ?: 30
          delay(retryAfter * 1000)
          return@repeat
        }
        500, 502, 503 -> {
          // Server error — exponential backoff
          delay(BASE_DELAY_MS * (1L shl attempt))  // 1s, 2s, 4s
          return@repeat
        }
        else -> false
      }
    } catch (e: IOException) {
      val isLastAttempt = attempt == MAX_ATTEMPTS - 1
      if (!isLastAttempt) delay(BASE_DELAY_MS * (1L shl attempt))
      else return false
    }
  }
  return false
}

DownloadCoordinator — Internal Queue Logic
@Singleton
class DownloadCoordinator @Inject constructor(
  private val hlsEngine:    HLSDownloadEngine,
  private val dashEngine:   DASHDownloadEngine,
  private val directEngine: DirectDownloadEngine,
  private val blobEngine:   BlobDownloadEngine,
  private val workManager:  WorkManager
) {
  private val activeSlots  = Semaphore(3)         // max 3 simultaneous downloads
  private val downloadQueue = ConcurrentLinkedQueue<DownloadRequest>()
  private val activeJobs   = ConcurrentHashMap<Long, Job>()

  suspend fun enqueue(request: DownloadRequest): Long {
    // 1. Disk space guard
    val available = StatFs(getCacheDir()).availableBytes()
    val estimated = request.estimatedBytes ?: 500_000_000L  // default 500MB
    when {
      available < 100_000_000L  -> throw DiskFullException("Less than 100MB free")
      available < estimated * 1.2 -> notifyLowDiskWarning()  // warn but continue
    }

    // 2. Create Room record immediately (QUEUED state)
    val downloadId = downloadRepository.create(request)

    // 3. Select engine
    val engine = when(request.mediaType) {
      MediaType.HLS_MASTER,
      MediaType.HLS_MEDIA   -> hlsEngine
      MediaType.DASH_MPD    -> dashEngine
      MediaType.BLOB_MSE    -> blobEngine
      else                  -> directEngine
    }

    // 4. Acquire slot (suspends if 3 already running)
    val job = scope.launch(Dispatchers.IO) {
      activeSlots.acquire()
      try {
        downloadRepository.updateState(downloadId, DownloadState.Fetching(0f))
        engine.start(request.copy(id = downloadId)).collect { progress ->
          downloadRepository.updateProgress(downloadId, progress)
          notificationManager.updateProgress(downloadId, progress)
        }
        downloadRepository.updateState(downloadId, DownloadState.Done(request.outputPath))
      } finally {
        activeSlots.release()
        activeJobs.remove(downloadId)
        processQueue()   // drain waiting items when slot freed
      }
    }
    activeJobs[downloadId] = job
    return downloadId
  }
}

suspend fun downloadDirectWithResume(
  url: String,
  destFile: File,
  headers: HarvestedHeaders
): Boolean {
  val existingBytes = if (destFile.exists()) destFile.length() else 0L

  // Step 1: Check server supports ranges
  if (existingBytes > 0) {
    val headResponse = okHttpClient.newCall(
      Request.Builder().url(url).head().applyHeaders(headers).build()
    ).await()

    val acceptsRanges = headResponse.header("Accept-Ranges") == "bytes"
    val contentLength = headResponse.header("Content-Length")?.toLongOrNull()

    if (!acceptsRanges || contentLength == null || existingBytes >= contentLength) {
      // Server doesn't support resume, or file already complete
      if (existingBytes >= (contentLength ?: 0)) return true  // already done
      destFile.delete()  // restart from zero
      existingBytes == 0L
    }
  }

  // Step 2: Build range request
  val request = Request.Builder()
    .url(url)
    .apply {
      if (existingBytes > 0) addHeader("Range", "bytes=$existingBytes-")
      applyHeaders(headers)
    }
    .build()

  // Step 3: Download (append mode if resuming)
  val response = okHttpClient.newCall(request).await()
  if (response.code !in intArrayOf(200, 206)) return false

  val appendMode = response.code == 206  // 206 = Partial Content
  response.body!!.byteStream().use { input ->
    FileOutputStream(destFile, appendMode).use { output ->
      val buf = ByteArray(32768)
      var bytesRead: Int
      var totalWritten = existingBytes

      while (input.read(buf).also { bytesRead = it } != -1) {
        output.write(buf, 0, bytesRead)
        totalWritten += bytesRead
        updateBytesProgress(totalWritten)
      }
    }
  }
  return true
}

Segment Validation Algorithm
fun validateSegments(
  segments: List<Segment>,
  tempDir: File,
  totalCount: Int
): ValidationResult {
  val missing  = mutableListOf<Int>()
  val corrupt  = mutableListOf<Int>()
  var totalBytes = 0L

  for (seg in segments) {
    val file = File(tempDir, "seg_${"%03d".format(seg.index)}.ts")

    // Check 1: File exists
    if (!file.exists()) { missing.add(seg.index); continue }

    // Check 2: File is not empty
    if (file.length() == 0L) { corrupt.add(seg.index); continue }

    // Check 3: File starts with valid TS sync byte (0x47 = MPEG-TS sync)
    val firstByte = file.inputStream().use { it.read() }
    if (firstByte != 0x47 && seg.url.endsWith(".ts")) {
      // For .m4s / fmp4 segments, check for ftyp/moof box header instead
      if (!isFmp4Segment(file)) corrupt.add(seg.index)
      continue
    }

    // Check 4: File size sanity — must be within 0.5x–5x of segment duration estimate
    if (seg.duration > 0f) {
      val expectedMinBytes = (seg.duration * 50_000f).toLong()   // ~50KB/s min
      val expectedMaxBytes = (seg.duration * 10_000_000f).toLong() // ~10MB/s max
      if (file.length() < expectedMinBytes || file.length() > expectedMaxBytes) {
        corrupt.add(seg.index)
        continue
      }
    }

    totalBytes += file.length()
  }

  return ValidationResult(
    missingIndices = missing,
    corruptIndices = corrupt,
    totalBytes     = totalBytes,
    isValid        = missing.isEmpty() && corrupt.isEmpty()
  )
}

suspend fun handleValidationFailure(result: ValidationResult, request: DownloadRequest) {
  val allFailed = result.missingIndices + result.corruptIndices
  if (allFailed.size > request.segments.size * 0.1) {
    // >10% segments bad → abort entire download
    throw ValidationException("Too many failed segments: ${allFailed.size}")
  }
  // Otherwise: re-download only failed segments
  redownloadSegments(allFailed, request)
}
Post-Mux Integrity Check
suspend fun verifyOutputFile(output: File, expectedDurationSec: Float?): Boolean {
  // Check 1: File exists and is non-empty
  if (!output.exists() || output.length() < 4096) return false

  // Check 2: Valid MP4 container — check ftyp box at offset 0
  val header = ByteArray(12)
  output.inputStream().use { it.read(header) }
  val boxType = String(header, 4, 4)  // bytes 4–7 = box type
  if (boxType != "ftyp" && boxType != "moov") return false

  // Check 3: File size sanity vs expected duration
  if (expectedDurationSec != null && expectedDurationSec > 0f) {
    val minExpected = (expectedDurationSec * 10_000f).toLong()  // 10KB/s floor
    if (output.length() < minExpected) return false
  }

  return true
}

@Singleton
class HeaderStore @Inject constructor() {

  // LRU evicts oldest-accessed entry when size exceeds 50
  private val cache = object : LruCache<String, TimestampedHeaders>(50) {
    override fun sizeOf(key: String, value: TimestampedHeaders) = 1
  }

  fun put(urlHash: String, headers: Map<String, String>) {
    cache.put(urlHash, TimestampedHeaders(headers, System.currentTimeMillis()))
  }

  fun get(urlHash: String): Map<String, String>? {
    val entry = cache.get(urlHash) ?: return null

    // TTL check: 30 minutes
    val age = System.currentTimeMillis() - entry.capturedAt
    return if (age < 30 * 60 * 1000) entry.headers else null
  }

  fun evictExpired() {
    val now    = System.currentTimeMillis()
    val cutoff = now - 30 * 60 * 1000
    // LruCache doesn't support iteration — snapshot and filter
    val snapshot = cache.snapshot()
    snapshot.filter { it.value.capturedAt < cutoff }
             .forEach { cache.remove(it.key) }
  }

  fun clear() = cache.evictAll()
}

Cookie Preservation & Authentication Handling

How session cookies captured from WebView traffic are safely preserved and replayed in download engine requests to authenticate against CDN and origin servers.

Authentication Flow — Full Pipeline
Step 1: Cookie harvest in shouldInterceptRequest()
Every request includes Cookie header cloned from WebResourceRequest.requestHeaders. Stored keyed by SHA-256(normaliseUrl(pageOrigin)). Also captures Authorization, Referer, Origin in the same entry.
Step 2: Cookie association with detected media
When DetectedMedia entity is created, the tab's most recent harvested headers (for the page origin) are attached: media.headersJson = JSON.serialize(harvestedHeaders). Stored in Room detected_media.headers_json column.
Step 3: Cookie injection into download requests
Every OkHttp request built by HLSEngine/DASHEngine/DirectEngine calls buildDownloadRequest(url, headers). Headers retrieved from HeaderStore (memory-first) or Room (disk fallback). Applied to each segment request and manifest fetch.
Step 4: CDN token forwarding (URL-based auth)
Some CDNs use query-param tokens (?token=xxx&expires=yyy) on the manifest URL. These tokens are forwarded to every segment URL by appending the base URL's query params to each resolved segment URL.
Step 5: Auth failure handling (403/401)
Download engine receives 401/403 on first segment. Attempt 1: evict cached headers, re-probe page origin via a silent background HEAD request, harvest fresh cookies. Retry segment. Attempt 2 failure → abort download with AUTH_FAILED error message.
Step 6: Cookie security
Cookies never written to disk in plaintext. In-memory HeaderStore only. When written to Room (header_cache table), encrypted via EncryptedSharedPreferences using AES-256-GCM backed by Android Keystore. Incognito: never persisted to Room.

    val baseUri  = Uri.parse(basePlaylistUrl)
    val CDN_TOKENS = setOf("token", "expires", "signature", "sign",
                           "key", "hdnts", "hdnea", "hmac", "Policy",
                           "Signature", "Key-Pair-Id")  // CloudFront params

    val tokenParams = baseUri.queryParameterNames
      .filter { it in CDN_TOKENS }
      .associate { it to baseUri.getQueryParameter(it)!! }

    if (tokenParams.isNotEmpty()) {
      val segUri = Uri.parse(absolute).buildUpon()
      tokenParams.forEach { (k, v) -> segUri.appendQueryParameter(k, v) }
      return segUri.build().toString()
    }
  }
  return absolute
}

Blob URL Architecture Deep Dive

Internal structure of blob: URIs, how they map to binary data, why they can't be downloaded directly, and how the Soul Browser extracts underlying media.

What a Blob URL actually is
Blob URI Anatomy
A blob: URI is a synthetic, origin-scoped, opaque reference. Format: blob:{origin}/{uuid} — e.g. blob:https://example.com/a3f9b2c1-…. The UUID is generated by the browser at URL.createObjectURL(blob) call time. It is not a network address. It points to a Browser in-process object registry keyed by origin + UUID.
The Object Store
The browser maintains a per-origin Blob URL store (a HashMap in Blink/V8). Entries are revokeable. Each entry holds either: (a) a raw Blob object (static binary data), or (b) a live MediaSource object (dynamic streaming). When the page calls URL.revokeObjectURL(), the entry is deleted. After revocation the URL becomes dead — a 404.
ℹ
Why blob: URLs cannot be downloaded with OkHttp A blob: URL is never sent over the network. It is resolved entirely inside the renderer process memory space. OkHttp, Android DownloadManager, or any external HTTP client will receive a "no such host" error because blob:https://… is not a DNS-resolvable hostname. The only valid consumer is the same browser origin that created it.
Blob URL Detection — Signal Path
① video.src setter hook fires
The JS bridge's HTMLMediaElement.prototype.src setter intercept fires when any page sets video.src = "blob:…". This is the primary blob detection signal. The value is relayed immediately to SoulBridge.onUrl(url, "VIDEO_SRC").
② MediaClassifier instant-returns BLOB_MSE confidence 1.0
if (url.startsWith("blob:")) return ClassResult(MediaType.BLOB_MSE, 1.0f) — this is the only hard-coded certainty in the classifier. No scoring needed. The blob detection path bypasses all other heuristics.
③ MSE detection hook fires in parallel
Simultaneously, MediaSource.prototype.addSourceBuffer hook fires with the MIME type (e.g. "video/mp4; codecs=avc1.42E01E,mp4a.40.2"). This triggers SoulBridge.onMseDetected(mimeType) → blobEngine.prepareCapture(tabId, mimeType), which pre-allocates the write buffer for binary accumulation.
④ BlobDownloadEngine enters CAPTURING state
Once user confirms download: engine state → CAPTURING. Every subsequent appendBuffer() call on the SourceBuffer is now serialized to disk via the base64 bridge channel. The engine accumulates all chunks ordered by chunkIndex.
⑤ isLast=true → DRAINING → FINALISED
When the final appendBuffer call fires (detected by the JS hook's isLast flag, set when the buffer is the last in a sequence), the engine writes all remaining chunks, closes the file, then initiates FFmpeg remux to valid MP4.
Mapping Blob URLs to Original Media Sources
Approach 1: appendBuffer interception (primary)
Hook SourceBuffer.appendBuffer and accumulate all binary data pushed into the buffer. This is media-format agnostic — works for fMP4 init + media segments, MPEG-TS segments, WebM chunks. The accumulated binary IS the original media stream. No mapping to original URL is needed.
Approach 2: XHR/Fetch URL correlation
Most MSE players fetch segments via XHR or fetch() before calling appendBuffer. If the XHR hook captures a URL like /hls/seg003.ts around the same timestamp as an appendBuffer call, that URL is the true source. This allows fallback to HLS/DASH engine if the URL is an M3U8 or MPD stream hidden behind a blob.
Approach 3: video.src pre-blob URL
Some players set video.src = directMp4Url initially and then switch to a blob. The video.src setter hook captures the direct URL first. If direct URL is an HLS/DASH manifest, the detection path switches from BlobEngine to HLSEngine or DASHEngine.
Approach 4: Network intercept fallback
shouldInterceptRequest continues to fire even when a blob is active — the media player still fetches segments over network. If those fetched URLs classify as HLS/DASH, the detector emits them as a parallel detected media entry, giving the user a choice between blob-capture and manifest-based download.

// BlobDownloadEngine — chunk accumulation model
class BlobDownloadEngine @Inject constructor(
  private val context: Context,
  private val tempFileManager: TempFileManager
) {
  // Per-tab in-flight capture state
  private val captures = ConcurrentHashMap<String, BlobCapture>()

  data class BlobCapture(
    val tabId:      String,
    val mimeType:   String,             // e.g. "video/mp4; codecs=avc1…"
    val outputFile: File,               // temp binary output stream
    val stream:     FileOutputStream,
    var totalBytes: Long = 0L,
    var chunkCount: Int  = 0,
    var state:      BlobState = BlobState.CAPTURING,
    // Ordered map: chunkIndex → base64-decoded bytes (for out-of-order delivery)
    val pendingChunks: TreeMap<Int, ByteArray> = TreeMap(),
    var nextExpectedIdx: Int = 0
  )

  fun prepareCapture(tabId: String, mimeType: String) {
    val tmpFile = tempFileManager.createBlobFile(tabId)
    captures[tabId] = BlobCapture(
      tabId    = tabId,
      mimeType = mimeType,
      outputFile = tmpFile,
      stream   = tmpFile.outputStream()
    )
  }

  // Called from @JavascriptInterface — runs on IO dispatcher
  fun onBlobChunk(b64: String, chunkIndex: Int, isLast: Boolean) {
    val cap = captures[currentTabId] ?: return
    if (cap.totalBytes > 200L * 1024 * 1024) {   // 200MB limit
      cap.state = BlobState.SIZE_EXCEEDED; return
    }

    val bytes = Base64.decode(b64, Base64.DEFAULT)

    // In-order write — queue out-of-order chunks
    if (chunkIndex == cap.nextExpectedIdx) {
      cap.stream.write(bytes)
      cap.totalBytes += bytes.size
      cap.nextExpectedIdx++
      // Drain any queued chunks that now follow
      while (cap.pendingChunks.containsKey(cap.nextExpectedIdx)) {
        val queued = cap.pendingChunks.remove(cap.nextExpectedIdx)!!
        cap.stream.write(queued)
        cap.totalBytes += queued.size
        cap.nextExpectedIdx++
      }
    } else {
      cap.pendingChunks[chunkIndex] = bytes  // queue for later
    }

    if (isLast) {
      cap.stream.flush()
      cap.stream.close()
      cap.state = BlobState.FINALISED
    }
    cap.chunkCount++
  }

  suspend fun finalise(downloadId: Long): File {
    val cap = captures[currentTabId]!!
    val rawFile = cap.outputFile
    val outFile = tempFileManager.createOutputFile(downloadId)
    // FFmpeg remux raw binary stream → valid MP4 container
    muxPipeline.remuxRaw(rawFile, outFile, cap.mimeType)
    rawFile.delete()
    return outFile
  }
}

MediaSource API & SourceBuffer Internals

How the W3C Media Source Extensions API works, the SourceBuffer state machine, and how Soul Browser hooks each stage.

MediaSource Object Lifecycle
1. MediaSource.constructor() → readyState = "closed"
JS page creates const ms = new MediaSource(). Object is unattached. A blob URL is immediately created: video.src = URL.createObjectURL(ms). This registers the MediaSource in the browser's object store and returns the blob: URI. Detection point: video.src setter hook fires with the blob URL here.
2. MediaSource "sourceopen" event → readyState = "open"
When the HTMLMediaElement loads the blob URL, it fires sourceopen. The page's event handler then calls ms.addSourceBuffer(mimeType). Detection point: MediaSource.prototype.addSourceBuffer hook fires — captures the codec string, triggers SoulBridge.onMseDetected(mimeType).
3. SourceBuffer.appendBuffer(buffer) — the data pump
The page fetches media segments (via XHR/fetch) and pushes ArrayBuffer/TypedArray data into the SourceBuffer. This is the continuous data feed. One appendBuffer call per segment. Detection point: SourceBuffer.appendBuffer hook converts each buffer to base64-chunked calls across the JS bridge to Android's BlobDownloadEngine.
4. SourceBuffer.updating flag & "updateend" event
After appendBuffer, the SourceBuffer goes into updating=true state while it processes the data internally (decode, index, buffer). The page must wait for "updateend" before calling appendBuffer again. The hook is applied BEFORE calling origAppend, so the bridge call happens while the data is still an in-memory ArrayBuffer, before the browser processes it.
5. MediaSource.endOfStream() → readyState = "ended"
When all content has been pushed, the page calls ms.endOfStream(). This signals playback can complete. The SourceBuffer hook treats this as an implicit "isLast" signal for the final appendBuffer. If the hook missed the isLast flag, an endOfStream hook can also trigger DRAINING state.
SourceBuffer Internal State Machine (Browser-side)
IDLE (updating=false) APPENDING (updating=true) REMOVING (updating=true) DETACHED (sourceBuffer removed)
IDLE --[appendBuffer(data)]→ APPENDING (fires "update" + "updateend" on completion) APPENDING --[internal processing done]→ IDLE (fires updateend) APPENDING --[abort()]→ IDLE (fires updateend) IDLE --[remove(start, end)]→ REMOVING (evicts buffered range) REMOVING --[removal done]→ IDLE IDLE/APPENDING --[ms.removeSourceBuffer(sb)]→ DETACHED
Multi-Track MSE — Audio + Video Separation
Two SourceBuffers = two streams
Modern MSE players call addSourceBuffer twice — once for video ("video/mp4; codecs=avc1…") and once for audio ("audio/mp4; codecs=mp4a.40.2"). Each returns a separate SourceBuffer instance. The hook must track BOTH and label chunks by their buffer's mimeType string.
Separate capture files for A+V
The BlobDownloadEngine creates two parallel output files: blob_video_{tabId}.raw and blob_audio_{tabId}.raw. Each SourceBuffer hook writes to its respective file. At finalise, both are passed to FFmpeg: -map 0:v -map 1:a -c copy output.mp4 to produce a muxed result.
// Hook must distinguish video vs audio SourceBuffer instance
function hookSourceBuffer(sb, mimeType) {
  const isVideo = mimeType.startsWith('video/');
  const isAudio = mimeType.startsWith('audio/');
  const trackId = isVideo ? 'V' : 'A';

  const origAppend = sb.appendBuffer.bind(sb);
  sb.appendBuffer = function(buffer) {
    try {
      const u8   = new Uint8Array(buffer instanceof ArrayBuffer ? buffer : buffer.buffer);
      const CHUNK = 256 * 1024;   // 256KB to avoid btoa stack overflow
      let   idx  = 0;
      for (let i = 0; i < u8.length; i += CHUNK) {
        const slice  = u8.subarray(i, i + CHUNK);

Injection Lifecycle & Guard Strategy
onPageStarted — Primary Injection Point
Called immediately when navigation begins. Script loaded from assets/js/bridge_injector.js and executed via WebView.evaluateJavascript(script, null). At this point the new JS context exists but the page DOM hasn't loaded — hooks are installed before any page JS runs.
IIFE + __SOUL_INJECTED guard
The entire script is wrapped in an IIFE (function(){ 'use strict'; if(window.__SOUL_INJECTED) return; window.__SOUL_INJECTED = true; … })(). On SPA (Single Page Apps) that re-use the JS context across routes, onPageStarted may fire again — the guard prevents double-wrapping of prototype methods, which would cause double-reporting.
Prototype method monkey-patching strategy
Hooks are installed on prototypes (XMLHttpRequest.prototype.open, MediaSource.prototype.addSourceBuffer), not on instances. This means ALL future instances created by the page inherit the hook automatically — no need to scan for existing elements. The original method is captured in a closure (const origOpen = XHR.prototype.open) and called at the end of the hook to preserve normal behavior.
Object.defineProperty for video.src (property intercept)
HTMLMediaElement.src is a property with getter/setter, not a plain method. Monkey-patching requires Object.defineProperty(HTMLMediaElement.prototype, 'src', {set(v){…}, get(){…}, configurable:true}). Marking configurable:true ensures the page can override again if needed (e.g. player framework re-defines it), and the hook can be re-applied on re-injection.
MutationObserver — late-arriving <video> elements
SPA frameworks may create <video> elements dynamically after the page loads. A MutationObserver watching document with {subtree:true, childList:true} captures any added video node and immediately reports its src if set. This covers React/Vue component mounts that add a pre-configured video element.
Silent exception swallowing
Every bridge call is wrapped in try { SoulBridge.onUrl(…) } catch(e) {}. If the WebView navigates and destroys the JS context while a hook fires, the SoulBridge object becomes undefined — this would throw without the catch. The catch also absorbs CSP-related SecurityErrors from cross-origin frames that somehow reach the hook.

class JavaScriptBridge @Inject constructor(
  private val signalBus: NetworkSignalBus,
  private val blobEngine: BlobDownloadEngine,
  private val scope: CoroutineScope
) {
  private val tabId = AtomicReference<String>()
  fun setTab(id: String) = tabId.set(id)

  // All @JavascriptInterface methods run on a WebView background thread.
  // Must NOT touch UI. Must NOT block. Dispatch to coroutine immediately.

  @JavascriptInterface
  fun onUrl(url: String, sourceType: String) {
    if (url.length > 4096) return     // defence: reject overlong strings
    val source = when(sourceType) {
      "XHR"       -> SignalSource.XHR_HOOK
      "FETCH"     -> SignalSource.FETCH_HOOK
      "VIDEO_SRC" -> SignalSource.VIDEO_SRC
      else        -> SignalSource.XHR_HOOK
    }
    scope.launch(Dispatchers.Default) {
      signalBus.emit(MediaSignal(url, source, tabId.get()))
    }
  }

  @JavascriptInterface
  fun onBlobChunk(b64: String, trackId: String, chunkIndex: Int, isLast: Boolean) {
    if (b64.length > 400_000) return   // 256KB b64-encoded ≈ 342KB text
    scope.launch(Dispatchers.IO) {
      blobEngine.onBlobChunk(b64, trackId, chunkIndex, isLast)
    }
  }

  @JavascriptInterface
  fun onMseDetected(mimeType: String) {
    scope.launch { blobEngine.prepareCapture(tabId.get(), mimeType) }
  }

  @JavascriptInterface
  fun onDrmDetected(keySystem: String) {
    // "com.widevine.alpha" | "com.microsoft.playready"
    scope.launch { signalBus.emitDrmSignal(keySystem, tabId.get()) }
  }
}

Two-Path Detection Architecture
Path A — shouldInterceptRequest (native, always-on)
Fires on Android's UI-level network stack for every sub-resource request made by the WebView. Captures HTTP method, URL, and ALL request headers including Cookie, Referer, Authorization. Cannot be disabled by page JS. Runs on a background thread. Blind to blob: URLs. Sees all iframes including cross-origin ones.
Path B — JS Bridge hooks (JS-level, hookable)
Fires when page JS calls XHR.open() or fetch(). Captures the URL at call time — before the request is actually dispatched. Does NOT see headers (set by page after open). Can be defeated by pages that patch back their own prototype methods. Only fires in the top-level document, not in cross-origin iframes. But catches blob: URLs that Path A cannot.

fun extractQualities(content: String, baseUrl: String): List<QualityOption> {
  val options = mutableListOf<QualityOption>()
  val lines   = content.lines()
  var i = 0

  while (i < lines.size) {
    val line = lines[i].trim()

    if (line.startsWith("#EXT-X-STREAM-INF:")) {
      // Parse attribute list: BANDWIDTH=1280000,RESOLUTION=1280x720,CODECS="avc1…",FRAME-RATE=30
      val attrs = parseAttributeList(line.removePrefix("#EXT-X-STREAM-INF:"))

      val bandwidth  = attrs["BANDWIDTH"]?.toLongOrNull()
      val resolution = attrs["RESOLUTION"]     // "1280x720"
      val codecs     = attrs["CODECS"]?.trim('"')
      val frameRate  = attrs["FRAME-RATE"]?.toFloatOrNull()
      val hdcp       = attrs["HDCP-LEVEL"]    // "NONE" | "TYPE-0" | "TYPE-1"

      // Resolution parsing
      val (width, height) = resolution
        ?. split("x")
        ?. let { it[0].toIntOrNull() to it[1].toIntOrNull() }
        ?: (null to null)

      // The next non-comment line is the variant playlist URL
      i++
      var variantUrl = ""
      while (i < lines.size) {
        val next = lines[i].trim()
        if (next.isNotEmpty() && !next.startsWith("#")) {
          variantUrl = URI.resolve(baseUrl, next).toString()
          break
        }
        i++
      }

      if (variantUrl.isNotEmpty() && bandwidth != null) {
        options.add(QualityOption(
          url         = variantUrl,
          bandwidth   = bandwidth,
          width       = width,
          height      = height,
          codecs      = codecs,
          frameRate   = frameRate,
          isHdcpGated = hdcp != null && hdcp != "NONE",
          label       = buildLabel(height, bandwidth)   // "1080p · 4.8 Mbps"
        ))
      }
    }
    i++
  }
  return options.sortedByDescending { it.bandwidth }
}

// Attribute list parser: KEY=VALUE,KEY="VALUE WITH SPACES",…
fun parseAttributeList(attrs: String): Map<String, String> {
  val map   = mutableMapOf<String, String>()
  val regex = Regex("""([A-Z0-9_-]+)=("(?:[^"]*)"|[^,]*)""")
  regex.findAll(attrs).forEach { m ->
    map[m.groupValues[1]] = m.groupValues[2].trim('"')
  }
  return map
}

Media Playlist Full Parse Algorithm
fun extractSegments(content: String, baseUrl: String): List<Segment> {
  val segs        = mutableListOf<Segment>()
  val lines       = content.lines()
  var durBuffer   = 0f
  var seqNum      = 0                    // EXT-X-MEDIA-SEQUENCE starting value
  var seqCounter  = seqNum
  var byteRangeStart: Long? = null      // EXT-X-BYTERANGE support
  var byteRangeLen:   Long? = null
  var discontinuity  = false
  var idx = 0

  for (raw in lines) {
    val line = raw.trim()
    when {
      line.startsWith("#EXT-X-MEDIA-SEQUENCE:") -> {
        seqNum     = line.removePrefix("#EXT-X-MEDIA-SEQUENCE:").toIntOrNull() ?: 0
        seqCounter = seqNum
      }
      line.startsWith("#EXTINF:") -> {
        // Format: #EXTINF:6.006,Title (title is optional)
        durBuffer = line.removePrefix("#EXTINF:")
                       .split(",")[0].toFloatOrNull() ?: 0f
      }
      line.startsWith("#EXT-X-BYTERANGE:") -> {
        // Byte range: #EXT-X-BYTERANGE:length[@offset]
        val parts = line.removePrefix("#EXT-X-BYTERANGE:").split("@")
        byteRangeLen   = parts[0].toLongOrNull()
        byteRangeStart = if (parts.size > 1) parts[1].toLongOrNull() else null
      }
      line == "#EXT-X-DISCONTINUITY" ->
        discontinuity = true

      !line.startsWith("#") && line.isNotBlank() -> {
        // URL line follows EXTINF — this is a segment
        val absUrl = URI.resolve(baseUrl, line).toString()
        segs.add(Segment(
          index        = idx++,
          seqNumber    = seqCounter++,
          url          = absUrl,
          duration     = durBuffer,
          byteRange    = if (byteRangeLen != null)
                           ByteRange(byteRangeStart ?: 0L, byteRangeLen!!) else null,
          discontinuity = discontinuity
        ))
        // Reset per-segment state
        durBuffer     = 0f
        byteRangeLen  = null
        discontinuity = false
      }
    }
  }
  return segs
}

fun resolveSegmentUrl(rawUrl: String, baseUrl: String): String {
  // Already absolute
  if (rawUrl.startsWith("http")) return rawUrl

  // Protocol-relative (//cdn.example.com/seg.ts)
  if (rawUrl.startsWith("//")) {
    val scheme = Uri.parse(baseUrl).scheme ?: "https"
    return "$scheme:$rawUrl"
  }

  // Relative path — resolve against playlist URL's directory
  return try {
    URI(baseUrl).resolve(rawUrl).toString()
  } catch(e: Exception) {
    // Fallback: manual base + path join
    val base = baseUrl.substringBeforeLast("/") + "/"
    base + rawUrl.trimStart("/"[0])
  }
}

Segment Validation Algorithm
fun validateSegments(files: List<File>, segments: List<Segment>): ValidationResult {
  val failed = mutableListOf<Int>()

  files.forEachIndexed { i, file ->
    when {
      // ① File existence
      !file.exists()               -> failed.add(i)

      // ② Non-empty
      file.length() == 0L          -> failed.add(i)

      // ③ Minimum size: duration × estimated_bitrate
      segments[i].duration > 0f &&
      file.length() < (100L * segments[i].duration.toLong()) -> failed.add(i)

      else -> {
        // ④ MPEG-TS sync byte check: first byte == 0x47
        val firstByte = file.inputStream().use { it.read() }
        if (firstByte != 0x47 && !isFmp4(file)) failed.add(i)
      }
    }
  }

  val failRate = failed.size.toFloat() / files.size
  return when {
    failed.isEmpty()   -> ValidationResult.Ok
    failRate > 0.10f   -> ValidationResult.TooManyFailed(failed)  // >10% abort
    else               -> ValidationResult.SomeFailedRetry(failed)  // retry these
  }
}

fun isFmp4(file: File): Boolean {
  // fMP4 starts with a box: length(4 bytes) + "ftyp" or "moof" or "styp"
  val header = ByteArray(8)
  file.inputStream().use { it.read(header) }
  val boxType = String(header, 4, 4, Charsets.US_ASCII)
  return boxType in setOf("ftyp", "moof", "styp", "moov")
}

Per-Segment Retry Algorithm (Exponential Backoff)
private suspend fun downloadSegmentWithRetry(
  seg: Segment, request: Request, destFile: File
): Boolean {
  val MAX     = 3
  val BASE_MS = 1000L

  repeat(MAX) { attempt ->
    try {
      val req = if (seg.byteRange != null)
        request.newBuilder()
          .addHeader("Range", "bytes=${seg.byteRange.start}-${seg.byteRange.start + seg.byteRange.length - 1}")
          .build()
        else request

      val resp = okHttpClient.newCall(req).await()
      return when(resp.code) {
        200, 206 -> {
          resp.body!!.byteStream().use { src ->
            destFile.outputStream().buffered().use { dst -> src.copyTo(dst, bufferSize = 65536) }
          }
          true
        }
        401, 403 -> {
          if (attempt == 0) { refreshAuth(seg.url); return@repeat }
          else return false
        }
        404           -> return false              // gone — don't retry
        429           -> {
          val wait = resp.header("Retry-After")?.toLongOrNull() ?: 30L
          delay(wait * 1000L); return@repeat
        }
        in 500..599   -> {
          delay(BASE_MS * (1L shl attempt))      // 1s, 2s, 4s
          return@repeat
        }
        else          -> return false
      }
    } catch(e: IOException) {
      if (attempt < MAX - 1) delay(BASE_MS * (1L shl attempt))
      else return false
    }
  }
  return false
}

class LiveHLSRecorder(
  private val mediaPlaylistUrl: String,
  private val headers: HarvestedHeaders
) {
  private val seenSegUrls    = mutableSetOf<String>()
  private val collectedSegs  = mutableListOf<File>()
  private var targetDuration = 5

  suspend fun startPolling() {
    while (state != LiveState.USER_STOPPED && state != LiveState.ENDLIST_DETECTED) {
      state = LiveState.FETCHING_MANIFEST
      val content = try { fetchManifest(mediaPlaylistUrl, headers) }
                    catch(e: IOException) { handleFetchFail(); continue }

      targetDuration = parser.getTargetDuration(content)
      val allSegs = parser.extractSegments(content, mediaPlaylistUrl)

      // NEW segments = those whose URLs we haven't seen yet
      val newSegs = allSegs.filter { it.url !in seenSegUrls }
      seenSegUrls.addAll(newSegs.map { it.url })

      state = LiveState.COMPARING_SEGMENTS
      if (content.contains("#EXT-X-ENDLIST")) state = LiveState.ENDLIST_DETECTED

      if (newSegs.isNotEmpty()) {
        state = LiveState.DOWNLOADING_NEW
        downloadSegments(newSegs).forEach { collectedSegs.add(it) }
      }

      state = LiveState.WAITING_NEXT_POLL
      delay(targetDuration * 1000L)  // poll interval = targetDuration
    }
    muxPipeline.concatSegments(collectedSegs, outputFile)
  }
}

DASH MPD Parsing Deep Dive

Full MPD XML structure, AdaptationSet selection, Representation quality picking, SegmentTemplate math, and the complete DASH data model.

MPD XML Structure & Data Model
MPD root — manifest metadata
Attributes: type ("static" = VOD | "dynamic" = Live), mediaPresentationDuration (ISO8601: "PT1H23M45S"), minBufferTime, suggestedPresentationDelay. Contains one or more <Period> elements. Static MPD = single period. Dynamic may have multiple.
Period — content segment
Attributes: id, start (offset from MPD start), duration. Contains <AdaptationSet> elements, one per track type. Most VOD streams have a single Period covering the full duration.
AdaptationSet — track group
Groups representations of the same content at different qualities. Attributes: contentType ("video"/"audio"), mimeType, codecs, lang, segmentAlignment. Contains <Representation> elements — one per quality level. Also contains <ContentProtection> for DRM.
Representation — single quality stream
Attributes: id, bandwidth (bits/sec), width, height, frameRate, codecs, sar. Contains segment addressing: <SegmentTemplate> (most common), <SegmentList>, or <BaseURL>.
SegmentTemplate — computed segment URLs
Template strings with substitution tokens: $RepresentationID$, $Number$, $Time$, $Bandwidth$. E.g. media="video/$RepresentationID$/seg$Number$.mp4" with startNumber="1" and duration="192000" (in timescale units).

fun parse(xml: String, baseUrl: String): DASHManifest {
  val doc    = DocumentBuilderFactory.newInstance().newDocumentBuilder().parse(xml.byteInputStream())
  val root   = doc.documentElement   // <MPD>
  val type   = root.getAttribute("type").ifEmpty { "static" }
  val dur    = root.getAttribute("mediaPresentationDuration").let { parseIso8601Duration(it) }

  val isDrm  = doc.getElementsByTagName("ContentProtection").length > 0

  val periods = doc.getElementsByTagName("Period")
  val videoAdaptations = mutableListOf<DASHAdaptation>()
  val audioAdaptations = mutableListOf<DASHAdaptation>()

  for (pIdx in 0 until periods.length) {
    val period = periods.item(pIdx) as Element
    val adaptSets = period.getElementsByTagName("AdaptationSet")

    for (aIdx in 0 until adaptSets.length) {
      val adaptSet = adaptSets.item(aIdx) as Element
      val contentType = resolveContentType(adaptSet)  // "video" | "audio" | "text"
      if (contentType == "text") continue

      val lang  = adaptSet.getAttribute("lang").ifEmpty { null }
      val reps  = parseRepresentations(adaptSet, baseUrl, dur)

      val adapt = DASHAdaptation(contentType, lang, reps)
      if (contentType == "video") videoAdaptations.add(adapt)
      else                          audioAdaptations.add(adapt)
    }
  }

  return DASHManifest(type, dur, videoAdaptations, audioAdaptations, isDrm)
}
SegmentTemplate — URL Generation Algorithm
fun generateSegmentUrls(
  repId:      String,
  bandwidth:  Long,
  template:   SegmentTemplate,  // from AdaptationSet or Representation
  totalDurSec: Double?,
  baseUrl:    String
): List<String> {
  val initUrl = template.initialization?.let { tpl ->
    expandTemplate(tpl, repId, bandwidth, null, null).let { URI.resolve(baseUrl, it).toString() }
  }

  return when {
    // ── SegmentTimeline variant ──
    template.segmentTimeline != null -> {
      val urls = mutableListOf<String>()
      if (initUrl != null) urls.add(initUrl)
      var time = template.startNumber.toLong()
      for (s in template.segmentTimeline) {
        repeat((s.repeat ?: 0) + 1) {
          val url = expandTemplate(template.media, repId, bandwidth, null, time)
          urls.add(URI.resolve(baseUrl, url).toString())
          time += s.duration
        }
      }
      urls
    }

    // ── Number-based variant ──
    template.duration != null && totalDurSec != null -> {
      val timescale  = template.timescale ?: 1
      val segCount   = ceil(totalDurSec * timescale / template.duration).toInt()
      val urls = mutableListOf<String>()
      if (initUrl != null) urls.add(initUrl)
      for (n in template.startNumber until template.startNumber + segCount) {
        val url = expandTemplate(template.media, repId, bandwidth, n, null)
        urls.add(URI.resolve(baseUrl, url).toString())
      }
      urls
    }

    else -> listOf()
  }
}

// Template expansion: replace $RepresentationID$, $Number%05d$, $Time$, $Bandwidth$
fun expandTemplate(
  tpl:        String,
  repId:      String,
  bandwidth:  Long,
  number:     Int?,
  time:       Long?
): String = tpl
  .replace("\$RepresentationID\$", repId)
  .replace("\$Bandwidth\$", bandwidth.toString())
  .replace(Regex("""\\\$Number(%0(\d+)d)?\\\$""")) { m ->
    val pad = m.groupValues[2].toIntOrNull() ?: 0
    number?.toString()?.padStart(pad, '0') ?: ""
  }
  .replace(Regex("""\\\$Time(%0(\d+)d)?\\\$""")) { m ->
    val pad = m.groupValues[2].toIntOrNull() ?: 0
    time?.toString()?.padStart(pad, '0') ?: ""
  }

// Select best video + best matching audio for download
fun selectRepresentations(
  manifest:   DASHManifest,
  pref:       QualityPreference,
  networkType: NetworkType
): SelectedTracks {
  // All video representations across all AdaptationSets, sorted by resolution
  val allVideoReps = manifest.videoAdaptations
    .flatMap { it.representations }
    .sortedByDescending { it.height ?: 0 }

  val selectedVideo = when (pref) {
    QualityPreference.BEST        -> allVideoReps.first()
    QualityPreference.MOBILE_SAFE -> allVideoReps.lastOrNull { (it.height ?: 0) >= 360 }
                                     ?: allVideoReps.last()
    QualityPreference.AUTO        -> if (networkType == NetworkType.WIFI) allVideoReps.first()
                                     else allVideoReps.lastOrNull { it.bandwidth < 2_000_000L }
                                          ?: allVideoReps.last()
  }

  // Select best audio: prefer language="en", then highest bandwidth
  val selectedAudio = manifest.audioAdaptations
    .flatMap { it.representations }
    .sortedWith(compareByDescending { it.bandwidth })
    .firstOrNull()

  return SelectedTracks(selectedVideo, selectedAudio)
}

suspend fun downloadAndMux(
  video:      DASHRepresentation,
  audio:      DASHRepresentation?,
  headers:    HarvestedHeaders,
  downloadId: Long
): File = coroutineScope {
  // Download video and audio segments concurrently
  val videoDeferred = async(Dispatchers.IO) {
    downloadRepresentation(video, headers, downloadId, track = "video")
  }
  val audioDeferred = audio?.let {
    async(Dispatchers.IO) {
      downloadRepresentation(it, headers, downloadId, track = "audio")
    }
  }

  val videoFile = videoDeferred.await()
  val audioFile = audioDeferred?.await()

  val outputFile = tempFileManager.createOutputFile(downloadId)

  return@coroutineScope if (audioFile != null) {
    muxPipeline.mergeAudioVideo(videoFile, audioFile, outputFile)
    outputFile
  } else {
    // Video-only: still produce valid MP4
    muxPipeline.remuxVideoOnly(videoFile, outputFile)
    outputFile
  }
}

// Download a Representation's init + media segments sequentially,
// then concat all to a single raw track file
private suspend fun downloadRepresentation(
  rep: DASHRepresentation,
  headers: HarvestedHeaders,
  downloadId: Long,
  track: String
): File {
  val segFiles = mutableListOf<File>()

  // Download init segment first (contains codec boxes)
  rep.initSegment?.let { initUrl ->
    val initFile = tempFileManager.createSegmentFile(downloadId, track, -1)
    downloadSegmentWithRetry(Segment(-1, initUrl, 0f), buildRequest(initUrl, headers), initFile)
    segFiles.add(initFile)
  }

  // Download media segments with bounded parallelism
  val segSemaphore = Semaphore(8)
  coroutineScope {
    rep.segments.mapIndexed { idx, url ->
      launch(Dispatchers.IO) {
        segSemaphore.acquire()
        try {
          val file = tempFileManager.createSegmentFile(downloadId, track, idx)
          downloadSegmentWithRetry(Segment(idx, url, 0f), buildRequest(url, headers), file)
          synchronized(segFiles) { segFiles.add(file) }
        } finally { segSemaphore.release() }
      }
    }.joinAll()
  }

  // Concatenate all segments to one raw track file
  val rawFile = tempFileManager.createRawFile(downloadId, track)
  val sorted  = segFiles.sortedBy { it.nameWithoutExtension.substringAfterLast("_").toIntOrNull() ?: 0 }
  rawFile.outputStream().use { out -> sorted.forEach { f -> f.inputStream().use { it.copyTo(out) } } }
  sorted.forEach { it.delete() }
  return rawFile
}

fun detectDrm(doc: Document): DrmInfo? {
  val cpNodes = doc.getElementsByTagName("ContentProtection")
  if (cpNodes.length == 0) return null

  for (i in 0 until cpNodes.length) {
    val node       = cpNodes.item(i) as Element
    val schemeUri  = node.getAttribute("schemeIdUri")
    val drmSystem  = when(schemeUri.lowercase()) {
      "urn:uuid:edef8ba9-79d6-4ace-a3c8-27dcd51d21ed" -> "Widevine"
      "urn:uuid:9a04f079-9840-4286-ab92-e65be0885f95" -> "PlayReady"
      "urn:uuid:94ce86fb-07ff-4f43-adb8-93d2fa968ca2" -> "FairPlay"
      "urn:mpeg:dash:mp4protection:2011"              -> "CENC"
      else                                            -> schemeUri
    }
    if (drmSystem != "mp4protection") return DrmInfo(drmSystem, schemeUri)
  }
  return null
}
Audio/Video Synchronization Notes
Why sync is not a concern in concatenation
DASH video and audio are independently timed via their own init segments. The -c copy -map 0:v:0 -map 1:a:0 FFmpeg command retains the original PTS/DTS timestamps from both tracks. FFmpeg's mux engine aligns interleaving automatically based on timestamps. No manual sync code is needed.
When sync can break
If init segment was not downloaded (missing moov/sidx box), PTS values in media segments may be relative with no base. FFmpeg will warn and may produce desynchronized output. Mitigation: always download and prepend the init segment before media segments in the raw file.

fun verifyOutputFile(file: File, expectedDurSec: Double?): VerifyResult {
  if (!file.exists())           return VerifyResult.Missing
  if (file.length() < 4096)     return VerifyResult.TooSmall

  // Read first 8 bytes: box_size (4) + box_type (4)
  val header = ByteArray(8)
  file.inputStream().use { it.read(header) }
  val boxType = String(header, 4, 4, Charsets.US_ASCII)
  if (boxType !in setOf("ftyp", "moov", "moof", "free"))
    return VerifyResult.InvalidContainer

  // Sanity: estimated file size vs duration (100 KB/sec minimum expected rate)
  if (expectedDurSec != null && expectedDurSec > 0) {
    val minExpectedBytes = expectedDurSec * 100_000  // 100 KB/sec floor
    if (file.length() < minExpectedBytes) return VerifyResult.SuspiciouslySmall
  }

  return VerifyResult.Ok
}

Failure Cases & Detection Limitations

Known hard limits of the detection architecture, unsolvable cases, and mitigations for each failure mode.

Fundamental Architectural Limitations
LIMITATION 1 — Cross-origin iframes
JS bridge is injected only into the top-level document. Cross-origin iframes (common for embedded video players from external CDNs) do not receive the hooks. Mitigation: shouldInterceptRequest fires for all frames, so network-level detection still works. JS-level blob capture is unavailable for cross-origin iframes. No workaround possible in the WebView security model.
LIMITATION 2 — DRM content
Widevine L1/L3 and PlayReady content decrypts in a trusted execution environment (hardware or software). The appendBuffer hook receives pre-decryption ciphertext — useless. EME detection halts capture. AES-128 HLS (non-EME) is the only "encrypted" type that remains downloadable because the key is fetched in cleartext.
LIMITATION 3 — WebRTC streams
WebRTC media (peer-to-peer video calls, live streams via RTCPeerConnection) bypasses all detection layers. WebRTC streams do not pass through shouldInterceptRequest, are not set on video.src, and do not use standard MSE appendBuffer. Detection: impossible at the WebView level without OS-level traffic inspection.
LIMITATION 4 — Service Worker interception
If the page registers a Service Worker that intercepts fetch calls, the JS bridge's fetch() hook sees the request but the Service Worker may modify/redirect the actual network URL. The final network URL may differ from what the hook captures. shouldInterceptRequest sees the actual URL but not SW-intercepted synthetic responses.
LIMITATION 5 — QUIC/HTTP3
If a CDN serves video over QUIC/HTTP3, Android WebView's shouldInterceptRequest may not fire (depends on Android version). JS hooks still fire, so URL is captured, but headers from the QUIC request are not harvested. Download falls back to using only the URL without cookies, which often fails for auth-gated content.
LIMITATION 6 — Obfuscated JS players
Some players obfuscate their XHR/fetch calls or use low-level ArrayBuffer over WebSocket for adaptive streaming. XHR hook won't fire for WebSocket frames. Detection coverage falls to shouldInterceptRequest-only (which sees TCP connections, not WS frames). Mitigation: scan for WebSocket URL upgrade requests and probe the WS URL for m3u8 patterns.

Critical Edge Cases
Process kill during MUXING
WorkManager CoroutineWorker re-executes on process restart. Room still shows MUXING. Worker detects all segments present and valid → skips download → jumps straight to mux. FFmpeg partial output deleted → full re-mux from existing segment files.
Process kill during FETCHING
Worker restarts. Segments already on disk are skipped (resume logic: file exists & size > 0). Only missing/zero-byte segments are re-fetched. WorkManager re-runs automatically on network reconnect via CONNECTED constraint.
Multiple PAUSED downloads on reconnect
WorkManager fires all CONNECTED-constrained jobs simultaneously. Semaphore(3) throttles — only 3 reach FETCHING. Others stay QUEUED. DownloadCoordinator priority queue orders them by score (size, type, user-initiated flag).
HLS live stream → user pauses mid-record
Live polling stops. Collected segments remain. State → PAUSED. On resume: re-fetch manifest (may have new EXT-X-ENDLIST). Continue appending new segments to the existing set. Mux the full combined set on completion.

DOWNLOAD ENGINE ROUTING:
  BLOB_MSE    → BlobDownloadEngine  (appendBuffer capture path)

HLS ENGINE:
  fetch master.m3u8 → parse quality variants → user selects
  fetch media.m3u8 → parse EXTINF → resolve URLs → check encryption
  AES-128: fetch key → store for FFmpeg | SAMPLE-AES: BLOCK
  isLive? → poll every targetDuration until ENDLIST or user stop
  Semaphore(8) parallel segments, 3× retry per segment
  validateSegments() → concat via FFmpeg → verifyOutput()
  → MediaStore insert → DONE

DASH ENGINE:
  fetch manifest.mpd → parse XML → select video+audio Representations
  ContentProtection? → BLOCK | generate segment URL lists
  concurrent A/V download (Semaphore(8) each)
  concat video segments → video_raw.mp4
  concat audio segments → audio_raw.mp4
  FFmpeg merge: -map 0:v -map 1:a -c copy → verifyOutput()
  → MediaStore insert → DONE

BLOB ENGINE:
  onMseDetected(mimeType) → prepareCapture() → alloc output files
  onBlobChunk(b64, trackId, chunkIndex, isLast) → decode → write ordered
  isLast=true → close stream → FFmpeg remux → verifyOutput()
  → MediaStore insert → DONE

DRM:

  EXT-X-KEY METHOD=SAMPLE-AES → BLOCK
  DASH ContentProtection schemeIdUri → BLOCK
